# Roadmap

- [x] **Milestone 1 — Repository and architecture:** modular Gradle build, Android app shell, Hilt composition, navigation, design tokens, hardware contracts/mocks, validated shared domain models, structured logging boundary, hardware mock tests, and foundational documentation.
- [ ] **Milestone 2 — Main player UI:** polished Home, Library, Albums, Artists, Songs, Now Playing, and Settings using mock music data.
- [ ] **Milestone 3 — Local playback:** Media3 service, MediaSession, queue, controls, and screen-off playback.
- [ ] **Milestone 4 — Music library:** incremental scanner, Room metadata, browsing, and unified search.
- [ ] **Milestone 5 — Playlists and favorites:** durable favorites, playlists, queue, and restoration.
- [ ] **Milestone 6 — E-paper simulator:** monochrome pages, touch, latency, ghosting, and screen-off development view.
- [ ] **Milestone 7 — Hardware abstraction hardening:** platform-backed development adapters and contract tests.
- [ ] **Milestone 8 — Spotify mock:** authorized-integration-ready controller and plausible UI behavior.
- [ ] **Milestone 9 — Device settings:** custom connectivity/audio/device screens and developer mode.
- [ ] **Milestone 10 — Production preparation:** factory-test skeleton, diagnostics, launcher strategy, and update architecture.

Milestone 2 should not begin until its visual/ergonomic questions in `DECISIONS.md` are reviewed. No physical hardware assumptions are blockers for the current foundation.
